# Security policy

Сообщайте об уязвимостях приватно: **chitushkam@gmail.com**. Тема письма:
`[Chitu security] краткое описание`. Не используйте публичные issues для
неисправленных уязвимостей. Публичный репозиторий и GitHub private vulnerability
reporting пока не подтверждены; email — действующий канал проекта.

Укажите затронутую версию/commit, компонент и конфигурацию, ожидаемое и фактическое
поведение, минимальный способ воспроизведения и возможное влияние. Удалите
действующие secrets и персональные данные. Не проверяйте чужие deployment без
разрешения владельца. При необходимости согласуйте защищённый обмен материалами
в первом письме; опубликованного PGP key сейчас нет.

До v1.0 поддерживается текущая ветка разработки и последний опубликованный RC,
если он существует. Сейчас RC только подготовлен локально; stable releases нет.
Исправление проверяется regression tests и security gates; advisory публикуется
после согласования исправленной версии и срока раскрытия с исследователем.
Срок ответа и SLA не гарантируются. При отсутствии ответа отправьте повторное
письмо; не размещайте рабочий exploit в публичном tracker.

Границы защиты и обязанности приложения: [production contract](docs/guide/production.md),
[threat model](docs/guide/security-audit.md), [authentication](docs/guide/authentication.md).
